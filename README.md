 -Descripción-
 Este proyecto consiste en una página web que permite consultar información de diferentes países del mundo. La aplicación muestra sus banderas, nombres, capitales, regiones y poblaciones.
 También cuenta con un buscador, un filtro por continente y botones para cambiar de página.

  --API REST utilizada--
Se utilizó la API pública REST Countries, que proporciona información sobre países en formato JSON.

Endpoint principal: https://restcountries.com/v3.1/all?fields=name,capital,region,population,flags

Para obtener los datos se utilizó fetch() junto con async/await.

--Instrucciones de uso--

1.Descargar los archivos del proyecto.

2.Abrir la carpeta en Visual Studio Code.

3.Ejecutar un servidor local con el comando python -m http.server 8000.

4.Abrir http://localhost:8000/ en el navegador.

5.Esperar a que carguen los países.

6.Utilizar el buscador para encontrar un país o el filtro para seleccionar un continente.

7.Utilizar los botones de paginación para consultar más resultados.
